# 🤖 Machine Learning Laboratory

This repository contains the Machine Learning Laboratory experiments completed as part of the B.E. Computer Science and Engineering curriculum. The programs are implemented using Python and popular Machine Learning libraries to understand fundamental concepts, algorithms, and their practical applications.

---

## 📚 Course Objective

The objective of this laboratory is to:

- Understand the fundamentals of Machine Learning.
- Learn data preprocessing and visualization techniques.
- Implement supervised and unsupervised learning algorithms.
- Evaluate model performance using different metrics.
- Gain hands-on experience with real-world datasets.

---

## 🛠️ Technologies Used

- Python 3.x
- Jupyter Notebook
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

---

## 📂 Laboratory Experiments

The repository includes implementations of the following experiments:

1. Data Preprocessing
2. Exploratory Data Analysis (EDA)
3. Linear Regression
4. Logistic Regression
5. Decision Tree Classification
6. Random Forest
7. K-Nearest Neighbors (KNN)
8. Naïve Bayes Classifier
9. Support Vector Machine (SVM)
10. K-Means Clustering
11. Hierarchical Clustering
12. Principal Component Analysis (PCA)
13. Model Evaluation Techniques
14. Performance Metrics and Confusion Matrix

> *The experiments may vary depending on the university laboratory syllabus.*

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/kaviya-18082006/ML-LAB.git
```

2. Navigate to the project folder

```bash
cd ML-LAB
```

3. Install the required packages

```bash
pip install numpy pandas matplotlib seaborn scikit-learn
```

4. Launch Jupyter Notebook

```bash
jupyter notebook
```

5. Open the desired experiment notebook and run all cells.
